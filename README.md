# Alena Supermart

Business website for Alena Supermart, a neighbourhood supermarket in Kutus, Kirinyaga County.

## Pages
- `index.html` — home, categories, full product listing, offers, testimonials
- `about.html` — story, values, how delivery works
- `contact.html` — order form, phone, hours, delivery info

## Run locally
Open `index.html` in a browser, or:

    python -m http.server 8000
